# Next read refinement

Next read should help a reader choose one book from their own library. Keep the books and the
next action prominent, with one honest reason for each suggestion.

## Shortlist pass

- Show the optional mood field immediately, with an explicit label and optional questions.
- Keep rereads and stopped books under a compact More options disclosure.
- Distinguish saving to the priority TBR shelf from starting a read or planning one. A successful
  save links directly to its actual shelf, including an existing reader-named priority shelf.
- Let the result grid use the space available inside the app shell. Keep long titles out of action
  labels; the book opens with its complete title. Reuse the card presentation in the guest library,
  whose Save for later action still describes its temporary sample state.
- Preserve scope, mood results, feedback, possession rules and the existing reading-write path.

## Following passes

1. Make optional comparison replace the shortlist rather than repeat it. Keep ordinary reading and
   TBR actions available, retain filters and planning drafts, and distinguish mood matches from
   fallback picks. Omit promotional copy and reduce repeated missing-metadata explanations without
   suggesting that an unknown series is standalone.
2. Add contextual launch and same-session resume for the live Add and Reading walkthroughs. Help
   should use the current screen and a deliberately selected book, preserve drafts, and never
   fabricate a successful save. Start over must be explicit and reset only guidance.
3. Add Next read and Planner walkthrough chapters against the settled controls. Keep persistent
   cross-session task bookmarks separate until their account-scoped data contract is reviewed.

## Verification

Check available, wishlist and whole-library scopes; deliberate reread and stopped-book inclusion;
free-text mood and question flows; navigation back to cached results; TBR destination and actual
membership; and successful reading start without changing possession. Include the guest library,
long titles, missing covers, all room palettes, small screens, keyboard use and enlarged text.
