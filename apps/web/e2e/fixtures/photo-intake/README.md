# Synthetic orientation photographs

`mirrored.jpg` and `rotated.jpg` are self-authored geometry/text rasters generated by
`scripts/fixtures/photo-intake.swift` with EXIF orientations 2 and 6. They contain no real book,
reader, location or photograph. The embedded GPS latitude is a synthetic metadata-stripping
control. Colored corner references are independently specified in the tests. These files prove
browser orientation/decoding behavior, not photographed-book recognition accuracy.
